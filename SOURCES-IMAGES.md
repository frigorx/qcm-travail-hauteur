# Sources et droits des visuels

## Famille d’illustrations `assets/illustrations/`

- Sujet : 25 scènes pédagogiques originales sur le travail en hauteur.
- Auteur / titulaire : inerWeb Édu — F. Henninot.
- Source : création originale interne pour ce QCM, construite manuellement en SVG.
- Droit d’usage : visuels propriétaires du projet ; aucune image tierce intégrée.
- Usages : affichage local et public avec le QCM, impression et fonctionnement hors ligne.
- Modifications : palette et traits conformes à la charte inerWeb ; chaque fichier contient un titre et une description textuelle.
- Preuve : sources reproductibles dans `tools/build-visuals.mjs` et historique Git du dépôt.
- Vérification : 24 août 2026.
- Crédit affiché : cartouche inerWeb Édu déjà présent dans le module.
